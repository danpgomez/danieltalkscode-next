This my learn-in-public blog and portfolio site built using [Next.js](https://nextjs.org), [TailwindCSS](https://tailwindcss.com/), and [TypeScript](https://www.typescriptlang.org/).

## Getting Started

```bash
npm run build
npm run dev

# or

npm run start
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
